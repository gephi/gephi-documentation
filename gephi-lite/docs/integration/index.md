title: Integrating Gephi Lite
sidebar_position: 1

Gephi Lite is an open-source web application and it can also be used within (or alongside) existing web applications.

There are several ways to integrate Gephi Lite into your application:

- **Deploy Gephi Lite:** Host your own instance.
- **Embed using a graph URL:** Open a graph directly in Gephi Lite using a URL.
- **Integrate using the TypeScript driver:** Interact with Gephi Lite programmatically from your application.

The following sections explain each approach.
